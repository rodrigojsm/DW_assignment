# Assignment 2 — Static Website
This individual assignment aims for students to demonstrate their ability to create web front-ends with high aesthetic rigor and a strong user experience, while using modern browser features. The student must create a **[static website](https://en.wikipedia.org/wiki/Static_web_page)** (composed of static pages) and host it using **[GitHub Pages](https://pages.github.com/)**.

The purpose of the website is entirely up to the student. Here are some ideas for what to create:

- A personal portfolio.
- A student club website.
- Website with information on a topic/hobby.
- Weather dashboard.

### Requirements
The website must be responsive and take advantage of the modern HTML/CSS/JS features taught in class. Furthermore, it must feature **at least once**:

- Dynamic interaction.
- CSS animation.
- Content generated by fetching information from a public API (for example, a list and links to your GitHub repositories) or your own static content on GitHub.
- No third party libraries.

### Materials to Submit
**Links to the repository and the website.** The repository must contain:

1. A `README.md` with a concise description of the purpose of the website.
2. A video on the **root directory** of the repository, up to 1 minute, demonstrating website interaction, named `SEEME`.

### Evaluation Criteria
- Organization of the development process using git 
  - Commit often
  - Clear descriptive commit messages
- Complexity of work done
- Quality of execution:
  - Visual rigor and user experience=
  - Usage of modern HTML/CSS/JS features
  - Readability and organization of the code (as per the principles discussed in class).
  - Elegance/simplicity of the solutions (solving the same problem simpler is better).

### Submission Deadline
Materials must be submitted through **Inforestudante** by **11:59 p.m. on November 17th, 2026** (Coimbra Time). This assignment accounts for **25%** of the final course grade.
